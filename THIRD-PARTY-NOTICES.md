# Avisos de componentes de terceiros

## Sunshine

O instalador do Windows inclui o instalador oficial do Sunshine, projeto da LizardByte, licenciado sob GPL-3.0. O código-fonte e os termos estão em https://github.com/LizardByte/Sunshine. O instalador conserva as telas, avisos e licenças do projeto original.

## Moonlight Android

O APK Android é construído a partir do Moonlight Android v12.2, projeto de código aberto licenciado sob GPL-3.0, com o identificador do pacote e o nome visível alterados para SmartToScreen. Código-fonte upstream: https://github.com/moonlight-stream/moonlight-android/tree/v12.2. O script de alteração e o workflow de compilação estão publicados neste repositório.

SmartToScreen é um projeto comunitário independente e não é afiliado à LizardByte nem aos mantenedores do Moonlight.
